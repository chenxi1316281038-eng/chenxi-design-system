# Lucion 设计质量检查

> P0 必须全部通过，否则继续修改。

## P0

- [ ] 使用 `brand-dna.md` 的嫩叶绿、柔叶绿、蜂蜜黄、暖白与炭褐；主色约 60%，点缀不超过 10%。
- [ ] 背景为暖白或薄荷白，整体清新明亮，有足够留白。
- [ ] 人物出现时使用 `assets/avatar.jpg` 或 `assets/character.png`，并符合 Lucion 的固定发型、蝴蝶发夹、嫩绿外套和蜡笔 Q 版画风。
- [ ] 没有写实/3D/stock photo、蓝紫渐变、霓虹、复杂背景、暗橄榄绿、蓝卷发/红蝴蝶结/圆眼镜等冲突元素。
- [ ] 标题为 `Noto Serif SC`，正文为 `Noto Sans SC`；无纯黑纯白。
- [ ] 有 900px 响应式断点，且移动端重新排列而非只缩小。
- [ ] 每个 section 的布局不同，使用 `clamp()` 做流式尺寸。
- [ ] 无默认 HTML 的 blockquote、ul/ol、table；使用组件库对应组件。

## P1

- [ ] 页面至少有一处克制的视觉记忆点：角色状态、叶片/蝴蝶线索、留白构图或大号低透明文字之一。
- [ ] 标题与辅助文字有明确层级，且行距、字距经过肉眼检查。
- [ ] 只使用 opacity / transform 的一次性入场效果，并尊重 `prefers-reduced-motion`。
- [ ] `::selection` 使用柔叶绿；链接或按钮有清晰 hover/focus 状态。

## P2

- [ ] 图片或人物恰当地溢出容器，仍不破坏阅读与响应式。
- [ ] 使用极少量蜂蜜黄或腮红粉作为情绪点缀。
- [ ] 以白底、绿意和内容层次建立节奏，而不是深色大面板或装饰堆砌。
